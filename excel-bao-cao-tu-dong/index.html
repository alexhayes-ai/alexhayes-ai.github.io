Chặng 1 · Để Claude nhớ bạn · ▶ 01:07

Cho Claude một tấm thẻ căn cước

Làm gì: tạo một file tên CLAUDE.md ghi bạn là ai, bạn làm việc gì, và quy tắc khi làm việc với bạn.

Vì sao: Claude Code rất hay quên. Mỗi phiên mới nó bắt đầu lại từ đầu và không nhớ cuộc trò chuyện hôm qua. Thứ nó luôn đọc lại là những file bạn để sẵn, và CLAUDE.md được đọc đầu tiên. Không có file này, lần nào bạn cũng phải giới thiệu lại, và Claude phải tự đoán cách bạn muốn làm việc. Đoán sai là bạn mất thời gian sửa.

Kiến thức cần biết
  • Có hai chỗ để CLAUDE.md. File chung cho mọi việc nằm ở ~/.claude/CLAUDE.md (trên Windows là C:\Users\[tên bạn]\.claude\CLAUDE.md). File riêng cho một dự án nằm ngay trong thư mục dự án đó.
  • Gõ /memory để xem Claude đang nạp những file nhớ nào.
  • Anthropic khuyên mỗi file CLAUDE.md nên dưới 200 dòng. Đây là mục tiêu, không phải giới hạn cứng. File càng dài càng tốn chỗ, và Claude làm theo càng kém. Mình giữ dưới 50 dòng.
  • CLAUDE.md là lời dặn, không phải luật cứng: Claude thường làm theo, nhưng không có gì bắt buộc nó.
  • Chỉ ghi những điều Claude không tự đoán được. Ví dụ: tên bạn, việc của bạn, quy tắc của bạn.

M01CLAUDE.md mẫu


# Về tôi
- Tôi là Minh, chủ một quán cà phê nhỏ. Tôi không rành kỹ thuật.
- Gọi tôi là "anh Minh". Trả lời bằng tiếng Việt, nói đơn giản, kết luận trước.

# Việc tôi đang làm
- Làm báo cáo bán hàng từ file Excel của quán.
- Tiền trong file là đô la (USD).

# Quy tắc làm việc
- Không sửa file gốc, ghi kết quả ra file mới.
- Ô ghi ERROR, UNKNOWN hoặc trống: coi như không có số liệu.
- Số dòng giữ + số dòng loại phải bằng số dòng gốc.
- Việc cần tôi quyết thì hỏi, đừng tự quyết.
- Hỏi trước khi xoá file hoặc gửi gì ra ngoài.


  
P01BMẹo thêm: để file luôn gọn


Thêm vào CLAUDE.md hai quy tắc: (1) khi file sắp quá 50 dòng, hỏi mình trước khi thêm; (2) khi mình phải nhắc một điều hai ba lần, hỏi mình có muốn thêm điều đó thành quy tắc không.

  
Vì sao: file tự phình ra theo thời gian. Quy tắc này bắt Claude hỏi bạn trước, nên file luôn ngắn và chỉ giữ những điều thật sự cần.

10.000 dòng lỗi, và một phép cộng để tin được

  
Làm gì: nhờ Claude làm sạch một file bán hàng bị lỗi, ghi ra một file mới, và cho bạn bằng chứng là nó không làm mất dòng nào.

  
Vì sao: file xuất từ phần mềm bán hàng thường có ô ghi lỗi, ô trống, ngày sai. Làm tay phải lọc từng cột, đoán từng ô, mất rất lâu. Claude làm nhanh, nhưng nhanh mà sai thì còn tệ hơn chậm. Vì vậy bạn phải đòi nó chứng minh.

  
Trong video, file mẫu có 10.000 dòng. Đây là bộ dữ liệu tập luyện công khai trên mạng, nên tên món bằng tiếng Anh và tiền là đô la. Bạn để ý: mình không gửi file vào khung chat. Claude Code làm việc ngay trên máy, nên nó tự tìm file trong thư mục bạn đang mở.


  
P03AChưa có file? Nhờ Claude tạo một file luyện tập có lỗi cài sẵn


Tạo giúp mình một file Excel bán hàng giả 200 dòng để luyện tập, tên luyen-tap.xlsx. Các cột: ngày, món, số lượng, đơn giá, thành tiền, cách thanh toán. Cố tình cài lỗi: vài ô ghi ERROR, vài ô UNKNOWN, vài ô trống, vài ngày viết sai định dạng, và vài dòng bị lặp. Ghi riêng một danh sách các lỗi đã cài để mình đối chiếu sau.

  
Vì sao dùng file giả: bạn biết trước có những lỗi nào, nên kiểm được Claude có tìm ra hết không. Làm với file thật thì luôn dùng bản sao, không làm trên file gốc.


  
P03Làm sạch file (gần với câu trong video, mình thêm dòng kiểm tổng)


Làm sạch file [tên file] trong thư mục này. Tiền trong file là [đô la (USD)]. Xuất ra một file Excel mới đã làm sạch, không sửa file gốc. Ô nào không chắc thì ghi "chưa rõ" và tô vàng. Ghi rõ ô nào đã sửa, dòng nào bị loại và vì sao. Kiểm lại: số dòng giữ cộng số dòng loại phải bằng số dòng gốc. Việc gì cần mình quyết thì dừng lại hỏi mình rồi mới làm tiếp.

P04Biến cách làm vừa rồi thành skill
